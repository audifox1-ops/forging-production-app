# 개선 후보 및 우선순위

## 우선순위 기준
- 핵심 목적에 중요한가 (가중치 3)
- 사용자가 자주 겪는 문제인가 (가중치 2)
- 개선 효과가 명확한가 (가중치 2)
- 기존 기능 망가뜨릴 위험이 낮은가 (가중치 1)
- 테스트로 검증 가능한가 (가중치 1)
- 유지보수성이 좋아지는가 (가중치 1)

## 제외 대상 (이번 사이클)

| 항목 | 제외 이유 |
|------|-----------|
| 엑셀 XML 수동 조작 개선 | 리스크 높음, 기존 동작 보장 필요 |
| Supabase 인증 구현 | 아키텍처 변경 초래, 별도 프로젝트로 처리 |
| 오프라인 지원 | 구현 복잡도 높음, 핵심 기능 아님 |
| 완전한 모바일 앱 전환 | 범위 초과 |
| 테스트 커버리지 80% 이상 | 시간 대비 효과 낮음 |
