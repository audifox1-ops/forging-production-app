# 앱 목적 및 핵심 흐름

## 1. 앱의 핵심 목적

**단조 공장의 일일 생산 실적을 기록, 관리, 보고하는 내부 업무 시스템**

- 4개 설비(P15, P5, R/M, P8)의 일일 생산량(제품, 황지)을 기록
- 근무조(주간/야간)별 실적과 계획을 비교
- 미달 사유를 체계적으로 기록하고 자동 보고서 생성
- 인쇄/엑셀 다운로드로 상위 보고에 활용

## 2. 주요 사용자

| 역할 | 설명 |
|------|------|
| 관리자(admin) | 전체 권한. 보고서 생성, 사용자 관리, 목표값 설정 |
| 총괄(manager) | 실적 입력/수정 권한. 보고서 관리 |
| 담당자(user) | 자기 설비 실적 입력 권한 |
| 열람자(viewer) | 읽기 전용 |

실제 사용자: 단조 공장 현장 관리자 및 담당자 (약 6명)

## 3. 사용자가 가장 자주 하는 작업

1. **실적 입력** (1일 2회): 근무조별 전일 생산실적 + 금일 생산계획 입력
2. **대시보드 확인** (수시): 생산 달성율, 미입력 현황 모니터링
3. **보고서 출력** (1일 1회): 인쇄/엑셀로 상위 보고
4. **미달 사유 작성**: 목표 미달 시 원인 및 만회대책 기록

## 4. 가장 중요한 기능

| 순위 | 기능 | 이유 |
|------|------|------|
| 1 | 생산실적 입력 | 앱의 존재 이유. 데이터 없이 다른 기능 의미 없음 |
| 2 | 대시보드 | 빠른 의사결정을 위한 현황 파악 |
| 3 | 보고서 인쇄/엑셀 | 실제 업무 보고에 사용 |
| 4 | 미달 사유 관리 | 품질 관리 및 개선 기록 |

## 5. 사용자가 얻어야 하는 최종 결과

- **매일**: 어제의 설비별 생산 실적과 계획 대비 달성율을 한눈에 파악
- **미달 시**: 원인을 체계적으로 기록하고 만회대책을 수립
- **보고 시**: 자동 생성된 보고서를 인쇄/엑셀로 즉시 출력
- **관리 시**: 월간/연간 생산량 추이를 집계표로 확인

## 6. 목적 달성을 방해하는 부족한 부분

| 부족한 부분 | 영향도 | 설명 |
|-------------|--------|------|
| 테스트 없음 | 높음 | 버그 발생 시 즉시 감지 불가, 리팩토링 위험 |
| 로딩 상태 미표시 | 중간 | 데이터 동기화 중 사용자 불확실성 |
| 모바일 최적화 부족 | 중간 | 현장에서 모바일로 접근 시 사용 불편 |
| 코드 스플리팅 없음 | 낮음 | 초기 로딩 시간 증가 (1.1MB JS) |
| 에러 바운더리 없음 | 중간 | JS 에러 시 전체 앱 비정상 종료 |
| 자동 동기화 불투명 | 낮음 | 동기화 상태가 사용자에게 명확히 표시되지 않음 |
